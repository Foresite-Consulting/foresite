# Foresite base theme

Source: Foresite Brand Guidelines v1.0 (the PDF is master). This is the base layer every client theme merges over, and the theme used for Foresite-branded demos.

## Placeholders in this folder

- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` are **placeholders** generated by `scripts/placeholder-icons.py` (a letter on a Jade square, labelled "PLACEHOLDER"). They are not the Foresite logo. Replace them with icons made from the logo masters held by the Brand & Design agent in the Foresite Project before any public demo.
- `client.logo` is `null`, so the app shows the app name as text where the logo would go. Do not redraw the logo; add the master SVG here and set `client.logo`.

## Additions since Brand Guidelines v1.0

These map existing palette colours onto new semantic tokens. No brand colour was changed.

| Token      | Light             | Dark               | Why                                                                                                                                                                |
| ---------- | ----------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `positive` | Moss `#3E7268`    | Jade `#6DA097`     | Direction indicator (icon only; the words use text colours). Jade on Serpentine is 4.39:1, so it may not be used as body text in dark.                             |
| `negative` | Ember `#C2412C`   | Coral `#FF6650`    | As above. Coral on Serpentine is 4.48:1, so icon only.                                                                                                             |
| `link`     | Ember (unchanged) | **Mist** `#F4F7F6` | The guide's Coral link on a Serpentine surface measures 4.49:1, just under AA 4.5:1. Links are always underlined, so Mist stays distinct. **For Joel to confirm.** |

## Chart semantics (fixed for every client)

Actuals solid, comparisons Fog, forecasts dotted (Ember on light, Coral on dark) with a shaded range. Only the colours come from the theme.
